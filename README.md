\# 🩺 Multi-Disease Risk Prediction System



An End-to-End Machine Learning Web Application built using Python, XGBoost, and Streamlit to predict the risk of Heart Disease, Diabetes, and High Cholesterol simultaneously based on lifestyle indicators.



\## 🚀 Features

\- \*\*Heart Disease Prediction:\*\* XGBoost Classifier with \*\*86.44% Accuracy\*\* and balanced recall.

\- \*\*Diabetes Risk Assessment:\*\* Tuned XGBoost with \*\*79.86% Accuracy\*\* optimized for high recall.

\- \*\*Cholesterol Classifier:\*\* Standard XGBoost with \*\*68.33% Accuracy\*\*.

\- \*\*Interactive UI:\*\* Built using Streamlit for an intuitive user experience.
